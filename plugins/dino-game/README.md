# dino-game（谷歌小恐龙）

在 Antigravity 右侧辅助面板中内嵌经典谷歌小恐龙（Chrome Dino）趣味小游戏（Stage 1 精简版），方便在等待 AI 执行长任务时随手解压，不打断主对话流程。

## 特性

- **单一右上角入口**：仅在右侧辅助面板右上角控制栏（自动对齐 URL 搜索栏与 `google-symbols` 图标行，兼容默认打开聚焦与展开动画）挂载小恐龙图标按钮，不在菜单列表与左侧边栏增加额外入口。
- **无边框透明融合**：自动继承右侧面板原生背景色并去掉画布与头部边框线，呈现纯净无背景的原生融合效果；关闭后无缝恢复原视图。
- **焦点隔离与 P 键暂停**：仅当游戏区域聚焦时响应 `Space` / `↑` / `↓` / `P` / `Esc`，按 `P` 键暂停/继续，绝不抢占主对话输入。
- **主题与双语适配**：自动适配 Antigravity 明暗主题；随 `zh-cn` 插件开关状态切换中文 / 英文界面与 `mod-manager` 摘要。
