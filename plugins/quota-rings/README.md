# quota-rings（左下角双模型额度环）

在 Antigravity 桌面端左侧边栏底部「设置（Settings）」右侧显示两个 `22×22px` 原生中性灰额度环（水平中心线对齐「设置」齿轮 `<svg>` / `.google-symbols` 图标，两环间隔 `10px`）：

- **左侧（圆角方形，`rx=7`）**：其它模型配额（如 Claude / GPT / DeepSeek 等，排除禁用与 BYOK 自定义模型）
- **右侧（圆形）**：Gemini 模型配额

## 核心特性

1. **双窗口 1:3 分割 + 单窗口自动降级**：
   - 当服务端同时下发 5 小时短窗与周窗（如 `RetrieveUserQuotaSummary`）时，自动按 1:3 分段显示（圆角方形上方 3/4 弧显示 5 小时额度、下方顺左右底角弯曲包裹底边显示周额度；圆形上方 3/4 圆弧显示 5 小时额度、下方约 90° 圆弧显示周额度；中央数字为 5 小时剩余百分比）。
   - 当 Antigravity 仅返回模型 `quotaInfo`（单一 `remainingFraction` 与 `resetTime`）时，自动降级为完整单环，不伪造周额度。
2. **组内瓶颈聚合**：默认取组内最小剩余比例；悬停显示两列对齐摘要与本地化重置时间（`MM/DD HH:mm`），存在多个不同比例模型池时附带精简子池明细。
3. **点击直达模型配额**：点击任意环自动打开「设置 → 模型（Models）」标签页并滚动定位配额区。
4. **原生视觉融合**：全程沿用 Antigravity 中性灰主题变量与 `.surface-glass` 浮层材质，并标记 `data-my-antigravity-no-i18n="true"` 隔离翻译。
