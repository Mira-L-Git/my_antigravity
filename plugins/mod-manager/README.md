# mod-manager（插件管理菜单）

将 Antigravity 桌面端左侧边栏左上角的 **Antigravity 品牌图标按钮**映射为 `My Antigravity` 插件管理菜单开关，方便在界面内单独启用或停用各个小插件：

- **精准映射入口**：仅拦截左上角纯 `<svg>` 品牌图标按钮（严格排除顶部文字菜单 `Antigravity`、侧边栏折叠、前进/后退与搜索按钮）；按住 **`Alt + 左键点击`** 仍可透传原生回首页功能。
- **简洁双语卡片列表**：自动扫描并展示其它已同步小插件（自动过滤 `mod-manager` 自身及 `protected` 核心项），列表项主标题显示原英文名（`id`），下方小字显示一句话功能摘要（优先读取 `mod.json` 的 `summary` / `summaryEn`），列表项内不展示单插件版本号或总数角标；`zh-cn` 开启时展示中文说明，未开启时自动切换为英文功能介绍与英文菜单提示。
- **主动检查更新**：菜单右上角显示当前套件总版本号（如 `v1.0.0`）与「检查更新 / Check Updates」按钮，**仅在手动点击时主动检查**（不进行被动后台推送）：
  - 若当前已是最新版本（按 `X.Y.Z` 从第一位到第三位依次比较，不小于 GitHub `main` 分支 `package.json` 中的版本号），在顶部提示「当前版本已是最新」；
  - 若发现新版本，在顶部显示新版本号（不展示更新日志），并将按钮替换为 **GitHub + 跳转箭头图标**，再次点击即通过系统默认浏览器打开 GitHub 项目主页。
- **持久化与平滑交互**：开关状态独立持久化至 `~/.gemini/config/plugins/my_antigravity/mods-state.json`（不因 `npm run sync` 被覆盖），变更后在底部提示并提供「立即重载 / Reload」按钮；配备 Web Animations API 缩放/淡入淡出过渡动画，支持点击外部或按 `Esc` 关闭。
